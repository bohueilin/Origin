Physical actor · mixed robot fleet

Robot proving ground

Paint your own floor (walls, hazards, human-only zones) and place a simulated mixed fleet (humanoid, AMR, quadruped, arm, drone). Watch it in 2D + 3D; the oracle returns finish, escalate or refuse for each robot type on one route across the floor you draw. Robot types differ only by two budget multipliers. You can sign the result in your browser; it grants no deployment permission.

Domain verifier: the deterministic drawn-floor oracle (finish / escalate / refuse, once per robot type).

Software actor · credential broker

Agent credential broker

An agent asks for access it does not hold. A named human approves one scoped grant, the broker mints an opaque lease handle: a reference to the credential, bound to that one grant, that cannot be exchanged for the secret. The value is resolved only at the tool-call boundary, then discarded. Revoke mid-flight and the next call fails closed.

Domain verifier: the grant ledger (approve / lease / revoke; every use recorded). Runs against a mock vault, no real credential is brokered here.

Physical actor · robot plan

Verified warehouse

A multi-robot fleet follows the oracle’s BFS-verified routes around the shelving. A deterministic wait-only coordinator holds robots for each other and for a scripted human marker, which does not yield. BFS (breadth-first search) finds each robot’s shortest grid route. Collision events, including with a finished robot parked in its cell or with the human marker, are counted from the frames. The run can be signed in your browser. Rendered in 2D and 3D.

Domain verifier: a deterministic grid oracle (finish / escalate / refuse), with collision events counted from the frames.

Capability is not permission, for any autonomous actor. These demonstrations explore a shared evidence contract with synthetic, seeded, replayable inputs. Results mean reproducible under this verifier, never “safe,” production autonomy, or robot certification. To run the evidence checks yourself, open the verification workbench; for the agent product, see what runs today and what is only proposed.
