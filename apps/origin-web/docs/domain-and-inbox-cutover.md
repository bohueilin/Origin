# Website identity and contact configuration

The maintained guide is [`docs/domain-and-inbox-cutover.md`](../../../docs/domain-and-inbox-cutover.md)
at the repository root.

The public website is **https://originphysicalai.com** and the public source repository is
**https://github.com/bohueilin/Origin**. Public metadata uses the website domain directly. Optional
build overrides only affect pages and discovery files; historical evidence remains unchanged.

DNS, redirects, contact mailboxes, and backend OAuth configuration require separately authorized
operational changes. Publishing a source update does not deploy the website.
