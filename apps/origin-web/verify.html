Which artifacts can I verify? See formats, checks, and verdict codes.
  • Action/Run Evidence: UNTRUSTED when intact but signed by a key Origin has not published, which covers every record made in a browser today. VOID when the digest, signature, coverage, freshness window or result replay fails, or when this verifier cannot replay the stated result. VALID needs a published issuer key; Origin has not published one. Even VALID would not mean the execution was verified: execution_verified is a separate field. No numeric code.
  • Origin Attestation: 0 valid · 1 payload tampered · 2 signature invalid · 3 wrong signer · 4 malformed
  • Crucible credential (unsigned): 0 valid · 3 tamper · 4 drift → VOID
  • ScoreReceipt (unsigned): 0 self-consistent · 3 tampered
  • Episode trace (unsigned): 0 intact · 2 chain tamper · VOID with no code when a published-TR-A002 check other than the chain fails
  • Merkle inclusion proof: included / not included
